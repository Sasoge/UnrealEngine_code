# AO 二分边缘降噪

当前实现已升级为文末的“城市场景修订”：共享连续滤波＋每盒体硬二分与碎边清理。下面保留前两版的设计与数据，便于对照，不代表当前仍使用稀疏 9×9 核。

日期：2026-10-17。针对录屏 `QQ20261017-180428.mp4` 中遮蔽二分边缘的细碎毛边。此前直接将单像素原生 AO 送入 `step`，阈值附近的采样波动会被放大成黑白跳变。

## 处理位置

```text
原生独立 AO → 几何边界保护的空间滤波 → 按局部波动收缩边缘 → 原有硬阈值 → 两档遮蔽
```

只处理硬二分判断用的 AO 可见度，不滤波间接光 RGB，也不对最终黑白遮罩做柔化。原始 AO、源有效性、AO 前光照和实验输入保持原值。现有原生强度模式不启用这个滤波；实际遮蔽二分输出、视图 38 以及受其影响的视图 37 共用相同判断值。

没有新增 RT、时序历史或运动重投影，不调整盒体 Pass 顺序。此空间处理不会产生自定义历史拖影，但不能保证消除原生 AO 所有随机波动或 TAA/TSR 的全部边缘变化。

## 邻域与边界保护

- 使用 9×9 高斯加权采样，默认覆盖输入渲染分辨率的 8 像素半径，标准差约 4 像素；默认采样间距为 2 像素。
- 同时计算可见度的加权均值和标准差，阈值输入为 `saturate(Mean + 0.5 * StdDev)`。可见度越高越不遮蔽，因此局部波动越大的边缘越容易退出暗部；均匀区域不受收缩偏置影响。这是风格化取舍，不是新的物理 AO。
- 邻居必须位于当前 ViewRect 中，具有同一提供方有效数据及最终间接数据；不跨天光/Lumen 数据来源混合。
- 由点采样深度重建邻居位置，对中心切平面做距离测试；法线夹角过大的像素被排除。
- 平面容差随像素世界尺寸变化，并限制在 0.25～2 厘米，避免轮廓处导数突增导致跨表面混合。此保守测试在强法线贴图或小曲率物体上可能减少可用邻居。
- 最后仍使用硬阈值，不新增软过渡。原生渲染抗锯齿仍可混合边缘像素。

使用输入纹理像素尺寸与实际点采样像素中心，检查 ViewRect 有效边界；不假设纹理范围等于视口范围。半径按内部渲染像素定义，所以降低 Screen Percentage 后对应的最终输出范围会变大。

## 对照开关

无需新增组件面板参数，默认自动启用。高级排查可使用：

```text
r.Toon.DeferredVolumes.AOFilterRadius 0   // 对照原来的单点硬阈值
r.Toon.DeferredVolumes.AOFilterRadius 8   // 默认
r.Toon.DeferredVolumes.AOFilterConservatism 0.5 // 默认收边强度，0 表示只滤波不收边
```

半径限制在 0～8，收边强度限制在 0～2。固定 81 个采样位置，增大半径会扩大采样间距；并非无限增加滤波质量。提高收边强度会主动舍弃不稳定的遮蔽边缘，可能使窄小的 AO 消失。原始视图 33 不受开关影响，视图 38 用于比较二分边界。

滤波增加邻域纹理采样成本，仅在相关输出/预览且源有效时运行；实际输出只在盒体有影响的像素运行。尚未记录正式 GPU 时间指标。

## 城市场景修订

录屏 `QQ20261017-190411.mp4` 暴露了前两版在复杂几何上的限制：用着色法线作为切平面法线可能排除法线贴图墙面上的有效邻居；半径 8 的 9×9 核每隔 2 像素采样，仍可能留下采样格差异。此前平板场景的统计不代表城市场景。

### 当前流程

1. 每视图生成几何法线和 AO 矩。几何法线从深度重建的相邻世界位置计算，每轴选择距离较近的一侧，避开轮廓深度断层；完全不读取材质着色法线。源标记仍区分 Lumen/天光/无效。
2. 连续 AO 做横向、纵向两次空间滤波。半径 8 时每轴连续覆盖 17 个整数像素，不再隔像素取样。邻居需来源一致、几何法线接近，且通过双向切平面距离检测。输出保留可见度均值、二阶矩、有效邻域支持度和来源。矩使用 FP32，避免半精度舍入将平坦区域变成假方差；几何法线使用 FP16。
3. 每盒体使用自己的阈值，对 `Mean + Conservatism * StdDev` 做硬二分。共享滤波不依赖盒体颜色或阈值。
4. 在几何边界约束下做 3×3 暗部开运算：先收缩黑色集合，再恢复有邻域支持的主体。最后与原始二分结果相交，明确禁止新增黑色区域。3×3 范围内不足 4 个同表面像素支持的微小区域也会被剔除。正常几何边缘不会仅因存在异表面邻居而被强制收缩；试验过的这一激进规则会打断长条和箱体轮廓，已放弃。窄小 AO 可能消失，这是用户接受的形状简化。
5. 实际合成和视图 38 使用同一处理结果。视图 33、材质/灯光 RGB、语义输入不变；没有新增历史、重投影或时序累积。

`DeferredToonAOFilter.usf` 提供五种着色器阶段：几何及初始矩、轴向滤波、阈值、暗部收缩、暗部恢复。连续部分同视图只执行一次；阈值与清理按盒体执行。RT 是 RDG 临时资源，不是跨帧历史。未启用硬 AO 且未预览相关视图时不生成这套滤波。

### 排查开关

- `r.Toon.DeferredVolumes.AOFilterRadius 0`：原始单点二分对照，也跳过碎边清理；默认 8。
- `r.Toon.DeferredVolumes.AOFilterConservatism`：保留，默认 0.5。
- `r.Toon.DeferredVolumes.AOCleanup 0/1`：关闭/开启碎边清理，默认 1。
- 在视图 38 下，`r.Toon.DeferredVolumes.AOFilterDebug 0/1/2/3` 分别显示最终硬遮罩、滤波后的连续 AO、邻域支持度、深度重建法线。该诊断只覆盖视图 38，默认 0。

支持度用来观察邻域是否被大量排除，不等于光照或 AO 强度。半径仍按内部渲染像素定义；深度断层处、亚像素细结构、视野外遮挡及原生 AO 输入波动仍可能变化。二分后的清理不会引入软过渡，后续原生抗锯齿可以混合边缘像素。
