## 数据来自哪里

在 `DiffuseIndirectComposite.usf` 中读取已经计算完材质漫反射响应、遮蔽和现存 Toon Lumen 加工的 `IndirectLighting.Diffuse`。它包含当前 Lumen 路径中参与漫反射的环境补光和反弹光，带真实材质颜色。不是原始入射辐照度，也不是无材质的参考白表面响应。

独立导出目标 `FSceneTextures::ToonIndirectDiffuse`：

未使用 Lumen 时，`ReflectionEnvironmentPixelShader.usf` 还会从 `SkyLightDiffuse` 的实际结果导出动态天光漫反射：包括材质响应、天空遮蔽和云遮蔽，位于加入 `ReflectionEnvironment` 之前。它和 Lumen provider 使用同一个接口；不把天光的镜面反射当成漫反射。现有测试场景的后处理体积将 GI 方法覆盖为 None，因此这条 provider 是保持原场景设置时的重要输入。

| 项目 | 契约 |
|---|---|
| RGB | 当前帧、主渲染分辨率、经过预曝光的间接漫反射贡献 |
| A | 1 表示支持的有效表面；0 表示未提供。A 不参与曝光转换 |
| 格式 | RGBA16F，1920×1080 时约 15.8 MiB |
| 生成 | 场景注册了盒体、使用传统 GBuffer 时创建；在间接光阶段每帧整张清零，支持的 provider 写入可用性 |
| 写入 | 原生合成像素着色器的独立 UAV，避免占用 dual-source blending 输出槽；没有额外全屏光照重算 |
| 使用 | RDG 显式声明读写依赖；盒体仍在 TAA/TSR 之前读取 |
| 无输入 | 不用 SceneColor 残差伪造 GI；调试显示黑色，调色沿用旧路径 |

此 RT 由该帧的盒体共享，并非每个盒体各创建一张。增加的成本主要是导出写入、整图清理及盒体采样；尚未做 GPU 时间定量对比。首版即使盒体未开启独立调色，也保留导出用于调试/实验分层；后续可用输入需求统计进一步裁剪。

没有导出 `IndirectLighting.Specular`、粗糙反射、SSR 或原生直接光。此前文件中的 Toon Lumen 修改和 `IndirectLighting.Specular = 0` 属于已有代码，本次不改写其行为。因此这里的“原生”是指当前引擎实际合成的漫反射，不代表未修改 Epic 基线。

首版覆盖 **Lumen、非 Lumen 动态天光 + 传统 GBuffer 的延迟不透明表面**。Substrate、独立 SSGI 的反弹光、Lightmap/VLM、Ambient Cubemap 等来源尚未单独导出；需要后续逐个接入。启用 SSGI 时若动态天光也参与画面，此 RT 只代表已接入的天光部分，不代表全部 GI。需后处理散射的 SSS 像素不参与独立调整，避免在扩散前提取、扩散后错误扣除。透明物体也不作为本阶段的独立表面层。有效性按像素记录，不以“RGB 是否为黑”判断。

后续扩展：[天光遮蔽独立控制](deferred-toon-sky-occlusion.md)。在保留这里的原生最终间接漫反射基础上，新增 AO 前天光和综合遮蔽输入；不会把 Lumen 的追踪遮挡伪装成可逆的 AO。

## 如何使用

1. 输出模式选择 **直接光调色 / Direct Light Grade**。
2. 在 **调试 / 缓冲视图预览** 中选择 **25 - 间接漫反射**。这是原始导出值，仍经过后续曝光与色调映射显示。
3. 用 **26 - 间接漫反射可用范围** 检查接入情况：白色为可用表面，黑色为未接入或无有效表面。可用且零 GI 的表面也显示白色。
4. 返回当前输出，展开 **风格化 | 间接漫反射**，启用 **独立调整间接漫反射**。

| 参数 | 作用 |
|---|---|
| 独立调整间接漫反射 | 默认关闭，旧场景沿用原来的其他光照权重；打开后间接层拥有独立控制 |
| 强度 | 默认 1；0 去除分离出的间接层 |
| 颜色 | 默认白色；乘色或替换的目标线性颜色 |
| 颜色替换 | 默认 0，保留原生空间分布并乘色；1 以目标色替换，包括可用但零 GI 的表面 |

颜色替换是艺术操作，不是物理补光：可以主动填亮原本没有间接光的表面。替换部分沿用现有“材质底色影响”，不重复乘到底色已经包含在内的原生 RGB 上。最终曝光、色调映射仍然生效，参数中的颜色不保证等于屏幕 RGB。

新控制仅作用于 Direct Light Grade。Toon Recompose 仍输出既有色板，其他模式不改变。新分组默认折叠，中英文切换同步覆盖分类、参数、提示和调试枚举。

## 合成与兼容

先定义预曝光空间下的量：

```text
O = 进入盒体系统前的 SceneColor
D = 有效原生直接漫反射
R = max(O - D, 0)                  // 原来“其他光照”的过渡残差
Iraw = 导出的间接漫反射
I = min(max(Iraw, 0), R)           // 按通道限制可从残差扣出的量
Remaining = R - I
```

只在独立调整已启用、像素有效时拆出 I。之后在场景线性空间加工：

```text
Tint = max(间接光颜色, 0)
B = lerp(1, GBuffer.BaseColor, 材质底色影响)
GradedIndirect = lerp(I / PreExposure * Tint, Tint * B, 颜色替换)
                 * 强度 * PreExposure
Output = GradedDirect + GradedIndirect + Remaining * OtherLightingWeight
```

未启用或不可用时：

```text
Output = GradedDirect + R * OtherLightingWeight
```

因此，**强度 1、白色、颜色替换 0、其他光照权重 1** 时，应还原启用独立调整前的结果，不会重复叠加 GI。启用独立调整后，“其他光照权重 0”只去掉剩余层；要只看直接光，还需将间接强度设 0。关掉独立调整则完全恢复旧权重语义。

残差限幅是当前框架的兼容措施。原始 GI 在后续雾、SSS、透明合成等处理前导出，盒体处的 SceneColor 已可能受这些处理影响，不能承诺对所有场景精确拆层。限幅保证中性参数不因负残差或重复扣光改变旧合成；调试 25 保留未经该限幅的原始 GI。未来如果需要精确处理雾和透明，必须同步设计分层合成时序，而不是增加一个不明来源的修正系数。

直接光的 `EffectiveLightBuffer.a`、阈值、档位、艺术阴影选区均不读取间接层。调色不会反过来改变档位。

- 不新增自定义时序历史，不移动盒体 Pass，不改变直接光输出。
- 所有引擎修改使用 `[DeferredToon]` 注释。
