# 间接漫反射严格二分

阶段调整：当前优先处理 [独立 AO 二分](deferred-toon-ao-two-tone.md)，保留 GI 原来的颜色和空间分布。本文的整层间接二分继续作为可选功能；不要把它当成只处理短程 AO 的开关。

日期：2026-10-17。基于现有间接漫反射与统一遮蔽接口，先提供两个固定色块，不增加新的 RT 或时序历史。

## 操作

1. 输出保持 **Direct Light Grade / 直接光调色**。
2. 展开 **风格化 | 间接漫反射**，开启 **独立调整间接漫反射**。
3. **着色方式**选择 **严格二分（无渐变） / Hard Two-Tone**。
4. 调整 **明暗阈值**、**颜色 / 亮部颜色**、**暗部颜色**。强度同时缩放两个颜色，不改变分档判断。
5. 用 **37 - 间接漫反射二分遮罩** 检查分区：黑为暗档，白为亮档。无有效间接光数据也为黑，应结合 26 数据有效性区分。

默认仍为“原有调色”，避免改变现有资产。切回后恢复原先的乘色/颜色替换行为，原来的参数值没有被删除或覆盖。

## 判断和输出

先按已有规则，从进入盒体前的场景残差中限制可提取的间接光；如开启统一强度或兼容遮蔽控制，仍应用对应的遮蔽前后 RGB 调整。2026-10-18 起，“遮蔽二分”使用已保存的 AO 前 RGB 作为分档输入，独立 AO 系数在调色/分档完成后施加。去预曝光后记为 `I`，计算：

```hlsl
Response = dot(max(I, 0), float3(0.2126, 0.7152, 0.0722));
Band = Response > 0 ? step(max(Threshold, 0), Response) : 0;
StyledIndirect = (Band == 1 ? LitColor : DarkColor) * Intensity;
```

`Response` 是场景线性亮度，非归一化 0～1 遮罩。阈值可大于 1；默认 0.1 只是起点，需按场景调整。零光照始终进暗档，即使阈值为零。

目前 RT 已含材质漫反射颜色，因此暗色材质可能被分到暗档。这个功能将当前间接漫反射的空间明暗转成色块，**没有新增无材质的参考白表面间接辐照度**，也不通过除材质颜色来近似恢复它。未来若需要与材质底色完全解耦的分档，应在提供方增加明确的照明输入。

严格二分不使用 `smoothstep`、过渡宽度或档内亮度乘色。也不把原生光照色度、材质底色、颜色替换权重继续乘入两个端点；旧版天光遮蔽染色在该模式下跳过，避免将连续 AO 再染回结果。统一强度和兼容遮蔽仍可在分档前影响分界；独立遮蔽二分的强度不再影响这个分档，而是在分档后缩放间接贡献，避免非黑色暗档重新填亮 AO。

间接层替换后只从原场景残差扣除一次原有间接量。直接光分档保持自己的控制，其余残差继续由 Other Lighting Weight 管理。像素不支持当前间接提供方时，保持原来的合成，不凭空补出亮/暗颜色。

## “没有过渡”的范围

这里保证的是：盒体完全覆盖区域内，**间接漫反射分档本身**只有两个固定线性颜色。同时开启独立 AO 后，还会乘两档遮蔽系数：强度 1 时可增加黑色，强度在 0 与 1 之间时最多有四种组合颜色。它不保证最终整个画面只有两色。

- 原生直接光、高光或未分离的残差仍可能产生渐变。
- 盒体混合权重不足 1、边缘羽化或多个盒体叠加，仍会与其他结果混合。
- TAA/TSR 可以在边缘产生抗锯齿像素；不关闭引擎抗锯齿，也不新增自定义时序。
- 后续曝光、色调映射、泛光等仍处理最终画面；参数色不等于屏幕 RGB。

初次图片检查错误地把盒体外原生画面纳入两色覆盖率；加入独立的盒体权重截图限定区域后，完整重跑通过，没有放宽两色覆盖率标准。测试日志仍包含已有两条启动期 Automation `Condition failed`；没有本次 Shader 编译错误或 Fatal。复杂材质、所有平台及多视口尚未全面覆盖。
