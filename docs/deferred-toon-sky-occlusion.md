# 天光遮蔽独立控制

日期：2026-10-16。基于 [间接漫反射第一阶段](deferred-toon-indirect-diffuse.md)，本次只拆普通动态 SkyLight 的局部遮蔽。保留原生最终间接漫反射和现有资产默认值，不移动盒体 Pass，不增加自定义时序累积。

## 为什么需要新输入

视图 9 原来名为“环境遮蔽”，实际只读取 `ScreenSpaceAOTexture`。天光 DFAO 不由这张纹理完整表达，所以墙面在视图 25 中有暗部、视图 9 却全白，并不矛盾。本次将视图 9 明确命名为“屏幕空间 AO”。

不能从最终间接漫反射亮度推断 AO，也不能通过除以 AO 可靠恢复照明：`GetSkyLightVisibilityData` 除了合并 DFAO、材质 AO 和屏幕 AO，还会改变天空 SH 采样方向，应用方向几何因子，并加入 SkyLight 的 Occlusion Tint。

## 数据与支持范围

在 `SkyLightingDiffuseShared.ush::SkyLightDiffuse` 中新增可选输出，保留原始返回值和旧调用包装函数。原生最终结果仍按原来的表达式计算；不导出分层的 shader 会优化掉不用的额外计算。

| 数据 | 定义 |
|---|---|
| 原生最终间接漫反射 | 原有 `ToonIndirectDiffuse`，原生材质响应、局部遮蔽、云遮蔽及已有自定义处理后的结果 |
| AO 前天光漫反射 | 用原始天光表面法线而非 AO 修改后的方向求 SH；保留相同材质、能量守恒、天光颜色、预曝光及云遮蔽；去掉局部遮蔽乘法和 Occlusion Tint |
| 天光综合遮蔽 | `saturate(SkyVisData.SkyDiffuseLookUpMul)`，1 无遮蔽、0 全遮蔽。包含原生 DFAO 控制、屏幕/材质 AO 合并及方向几何因子；不是纯 DFAO，更不是照明前后相除 |

新物理资源 `FSceneTextures::ToonSkyDiffuseBeforeAO` 是 RGBA16F：RGB 保存预曝光的 AO 前照明，A 保存综合可见性。A=-1 表示不可用，A=0 是有效的完全遮蔽，不能用 RGB 或 A 是否为零判断可用性。

每帧按主渲染分辨率创建一张、整张清为 `(0,0,0,-1)`，所有盒体共享；RDG 显式声明 UAV 写入和 SRV 读取。1920×1080 约增加 15.8 MiB。沿用现有“场景有盒体就导出”的策略，因此暂时也会为 Lumen 场景分配并清理这张无有效像素的资源；需求裁剪尚未实现。额外成本包括一次无 AO 的 SH 求值、UAV 写入/清理及盒体采样，尚无 GPU 性能实测。

当前支持普通动态 SkyLight 的传统 GBuffer 表面。Unlit、需要后续散射的 SubsurfaceProfile、Hair 和已有自定义 Toon 禁用天光的像素不提供独立遮蔽数据；天空背景也无效。Lumen、Substrate、Lightmap/VLM、Ambient Cubemap 暂不提供这组拆分数据。Lumen 的原有最终间接漫反射仍可使用。

这是“局部 AO 应用前”的天光，不是完全无遮挡的 GI。云遮蔽仍然保留。Lumen 中因追踪被几何体阻挡而少收到的光，也不能用这条接口逆向还原；以后仅在实际应用独立 AO 的位置增加对应 provider。

## 盒体操作

1. 输出选择“直接光调色 / Direct Light Grade”。
2. 在“间接漫反射”中启用“独立调整间接漫反射”。首次检查请保持强度 1、白色、颜色替换 0；原来的间接光颜色替换为 1 时会覆盖照明空间分布，因此不适合观察去 AO 前后的照明差异。
3. 展开默认折叠的“天光遮蔽”，启用“独立调整天光遮蔽”。
4. 将“遮蔽强度”从 1 调到 0，观察局部天光暗部消失。直接光投射阴影、材质底色、云遮蔽不会因此消失。
5. 要独立改色，保持遮蔽强度大于 0，设置“遮蔽颜色”和“颜色替换”。替换只作用于综合遮蔽标出的间接光部分，不染直接光或高光。

默认开关关闭；启用后的中性参数为强度 1、颜色替换 0。没有接入数据时保持原来结果，不以白色 AO 或全黑 GI 误判整张画面。中英文界面同步提供参数与提示。新字段不影响已有枚举编号或资产默认行为。

| 调试 ID | 用途 |
|---|---|
| 9 | 屏幕空间 AO，已有输入，改名明确含义 |
| 25 | 原生最终间接漫反射，始终是未经盒体加工的输入 |
| 26 | 间接漫反射数据有效性，改名避免被理解为空间影响范围 |
| 27 | 天光漫反射（AO 前）；无效处黑色 |
| 28 | 天光综合遮蔽；白为无遮挡，黑为遮蔽；无效处白色中性值 |
| 29 | 天光遮蔽数据有效性；白有效、黑无效，用它区分“无 AO”和“未接入” |

调试仍经过 UE 后续色调映射，白色数值未必显示为屏幕 255。新的 AO 和有效性预览在输出时匹配 PreExposure，避免预曝光变化改变显示；资源的 A 本身永远不乘曝光。

实验分层增加稳定语义 ID **16 SkyDiffuseBeforeAO**、**17 SkyOcclusion**，共享同一物理纹理、独立解码。16 只对 RGB 去预曝光，17 是无量纲可见性。缺失输入分别回退黑色/白色。没有新增第二套纹理贴图参数；后续独立 AO 纹理映射可消费这两个语义，不需要改原生光照 producer。

## 合成顺序和公式

沿用第一阶段的原始 SceneColor 残差提取。下面 N、U、E 都是预曝光颜色：

```text
N = max(原生最终间接漫反射, 0)
U = max(AO 前天光漫反射, 0)
E = min(N, 可用 SceneColor 残差)
K = N > epsilon ? E / N : 1             // 按颜色通道计算残差预算，不是除以 AO
s = 遮蔽强度 [0,1]
调整后间接光 = max(E + (U - N) * K * (1-s), 0)
```

只有开关启用且新数据有效才调整；默认 s=1 时严格使用 E。s=0 时恢复 AO 前贡献，包含移除方向调整和原生 Occlusion Tint 的效果，不能承诺每个像素都更亮。N=0 时不丢失恢复完全遮蔽区域照明的能力。

之后按现有“间接漫反射颜色/替换/强度”调色，再应用独立遮蔽换色：

```text
换色权重 = (1 - 综合可见性) * s * 遮蔽颜色替换
目标色 = 遮蔽颜色 * 已有材质底色影响 * 间接光强度 * PreExposure
处理后的间接光 = lerp(间接光调色结果, 目标色, 换色权重)
最终 = 已处理直接光 + 处理后的间接光 + (原残差 - E) * 其他光照权重
```

从残差只扣原生 E 一次。没有再将 AO 乘到已经遮蔽的原生结果上。强度 0 会同时关闭独立遮蔽换色。换色是艺术操作，允许把暗部染亮；它并不表示物理上增加了一盏光。直接光档位与选择逻辑不读取这些新参数。

SceneColor 残差预算仍是第一阶段的兼容措施，不能宣称对雾、透明等后续合成精确拆层。综合遮蔽值也不能精确编码方向改变与加色的全部效果；为此保留实际 N/U 两个照明结果，没有用简单乘积伪造原生合成。

## 验证方法

使用 `Tests/DeferredToon/verify_indirect_diffuse_editor.py`，附加 `-ToonSkyOcclusionSplit`，在独立 D3D12 离屏编辑器进程中临时调整测试场景，不保存资产。图像检查脚本为 `Tests/DeferredToon/check_sky_occlusion_images.py`。

严格图像比较使用临时指定的固定 DaylightAmbientCubemap，隔离天空捕获内容变化。可另加 `-ToonSkyOcclusionCapturedSky` 观察场景原有捕获天光，输出至独立目录；这组不能仅凭跨帧亮度差异判断新导出有曝光错误，必须同时对照原生最终间接光。

检查中性兼容、真实 AO 空间变化、去 AO/换色效果、强度 0 禁止换色、直接光分档不变、RGB/遮蔽预曝光稳定性、关闭 SkyLight 后的回退、Lumen 不冒用天光拆分数据、GI 切换恢复、TSR 降分辨率输出。
